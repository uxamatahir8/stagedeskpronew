## Inloggen met een code

Op de inlogpagina kun je kiezen voor **Inloggen met een code**. Je krijgt een code van zes cijfers per e-mail, tien minuten geldig. Klanten loggen altijd zo in.

## Wachtwoord vergeten

Kies **Wachtwoord vergeten** en volg de link in de e-mail.

## Tweestapsverificatie

Onder je profiel zet je tweestapsverificatie aan met een app zoals Google Authenticator of 1Password. Bewaar de herstelcodes op een veilige plek. Kwijt? Neem contact op met support.
